# 任务

## 已完成

- 七天纵向切片核心规则与自动存档。
- 32 个事件、六个地点、四名 NPC 和七个结局。
- 主菜单、角色初始化、校园地图、事件、设置、暂停和结局 UI。
- 离线 AI 建议与核验/误导事件。
- 原生规则测试、UI 冒烟测试和完整流程模拟。
- Windows x86_64 debug 导出与 PCK 启动验证。
- 64 张用户校园照片的地点随机背景、昼夜道路滚动过渡与存档恢复。
- 新版 Windows EXE 和 PCK 的离线自动启动验证。
- 简易、中等、困难三档难度及完整数值倍率结算。
- 长曝光高压眩晕界面与三种即时应对选择。
- 65 张照片恢复原始分辨率与原始 JPEG 文件，并通过 SHA-256 核对。
- 半透明事件界面、原比例照片相框和 EXIF 方向显示层。
- 操场具体运动名称与教学区真实建筑名称的场景化叙述。
- 七层音频总线、14 类语义交互音效、独立音量设置与压力音效开关。
- 主菜单、校园、道路和六地点的昼夜程序化声景及两阶段交叉淡化。
- 声景冒烟测试、完整 UI 回归、视觉捕获与 Windows 0.7.0 构建验证。
- “山大夜航 · Neo Glass”共享毛玻璃、聚光悬停、程序化背景、发光进度控件与全流程界面统一。
- Neo Glass UI 自动回归、1280×720 视觉基线与 Windows 0.8.0 构建验证。
- 选项即时反馈、单次纹理传递、四张 LRU 原图缓存和道路/目的地/下一幕后台读取。
- 无纯黑背景、无选项方框的校园纪实编辑式事件选择页样板，以及鼠标/键盘共用的页边焦点反馈。
- 65 张照片的比例清单、电影横幅/横幅画报/竖幅跨页三版式系统和四类代表场景视觉验证。
- 全屏纸质校园导览图、六类原创建筑热点、NPC 地点落点、截止日便签、当前位置与选中路线。
- 地图的单地点底部说明、“前往这里”二段确认和原有两秒路途无缝衔接。
- 期末周档案封面主菜单、带原图附图和地点圈注的目录入口，以及双页七天策略路线档案。
- 三条路线的真实收益、压力和事件倾向差异，以及相应核心/UI 自动回归。
- 纸质选择回执、单一白色纸质地图活动浮签，以及鼠标/键盘一致的地点预览反馈。
- 路线登记页的清晰档案署名字段、无机械倒计时文案的道路转场、学生行走进度插画和无周期高频脉冲的校园声景。
- 地点确认后保留已选地图直至道路照片就绪的单一风景转场，以及无“鼠标所指”辅助语的白色活动浮签。
- 无圈注遮挡的档案封面附图，以及地图、事件、照片场景共用的大号四项状态带。
- 纸质 AI 学伴核验单，明确区分建议、依据和风险，不再使用旧深色提示弹窗。
- 四名地图同伴的真实可点击路线、专属事件优先触发、关系门槛与事件耗尽后的日常互动。
- 删除项目级旧加载场景、自动加载和残留加载脚本；全部地点仅保留校园风景道路转场。
