- 完整七天模拟：简易难度的平衡、学习、AI 三条路线，以及中等、困难的平衡路线，均在 33 个行动后到达项目展示并产生结局。
- 0.12.0 使用 Windows OpenGL 3.3 和 NVIDIA GeForce RTX 5060 Laptop GPU 重新截取 1280×720 视觉基线；档案封面、同伴路线、AI 核验单、校园总览、道路学生进度、事件、选择回执与设置等画面均成功写出。

- 路线页检查：开场提问、档案署名与姓名输入拥有独立垂直空间；三张错层文件页签和简易/中等/困难三节点强度轴均可鼠标及键盘操作；右页五项说明会随路线切换，并与真实结算规则一致。
- 选择回执检查：事件、固定日程、延迟后果、跨日与手动存档的结算均使用暖色纸张回执；原图保持当前版式，右侧只保留结果摘要和“翻页”操作，不再回退到旧深色结果面板。
- 地图悬停检查：建筑只保留一套白色纸质活动浮签，显示真实地点名和具体可做行动；已移除“鼠标所指”提示字样。Godot 黑色系统 tooltip 已关闭，不再产生双层文字，且不消耗时段、不改变选择状态。
- 同伴检查：地图上的程乐天、周启明、林知夏和宋小雨会显示当前关系值；点选后底部展开人物身份、所在地点、相处习惯和定向行程。抵达后优先触发该人物事件，没有未读事件时使用数据驱动的日常互动继续改变关系与状态。
- AI 学伴检查：旧深色弹窗已替换为纸质核验单，四项状态、建议正文、判断依据、风险提示和返回地图操作均无重叠；页面明确提示玩家自行判断，不将 AI 建议包装为唯一答案。
- 照片层检查：事件页不再使用玻璃着色器或黑色遮罩。原图位于独立照片舞台，纸色留白承载叙事和选择；照片只进行显示方向旋转和 0.42 秒淡入。
- 交互检查：六个地点不再通过等宽卡片抬升，而是使用各自建筑轮廓的变色、定位标和地图路线；键盘焦点与鼠标点击均可到达建筑热点，确认行程只保留一个底部操作。
- 点击响应检查：本次无界面实测中，事件选项在 0.33 ms 内完成锁定并显示结算反馈；地点点击会先锁定地图热点，并在道路照片可用后直接进入唯一的风景道路转场，不再出现独立的深色“正在准备前往”页面。地图保留期间不重复触发入口，结果页复用相同 `Texture2D` 对象，没有重新解码当前照片。
- 后台读取检查：道路与目的地照片并行请求；固定事件与压力危机的冷照片在保留当前画面时由线程读取，不再插入另一张准备页。访问多类场景后 LRU 缓存仍不超过四张。
- 自适应照片检查：44 张显示竖图使用 456×540 左右跨页，21 张 4:3 或近方形图片使用 640×480 画报板；未来宽高比达到 1.5 的新横图会自动使用 1280×720 电影式画布。照片完整等比显示，交互区域不与照片重叠。

- 图片检查：65 张项目副本与用户原图逐张 SHA-256 一致，总计 313.16 MiB；未缩放、未重新编码、未二次压缩。
- 场景检查：中心校区六个地点、操场八类照片、教学区具名空间和固定日程事件均能显示对应真实名称；事件标题、正文、选项和结果支持当前场景替换。
