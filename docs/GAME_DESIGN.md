# 游戏设计

## 核心循环

查看日程与状态 → 点击地点 → 选择行动或处理事件 → 应用即时结果 → 推进时段 → 处理延迟后果 → 自动存档。

## 固定规格

- 时间：7 天，每天早晨、上午、下午、晚上、深夜。
- 地点：宿舍、图书馆、教学楼、实验室、食堂、操场/校园道路。
- 数值：学习、项目、精力、压力、四名 NPC 关系；AI 依赖度隐藏。
- 关键节点：第 5 天上午考试，第 7 天下午项目展示。
- 结局：全面发展、学习强者、技术达人、AI 协作高手、温暖校园、AI 过度依赖、压力失控。

选择不能只替换台词。代表性事件至少同时影响即时数值和后续事件、关系或结局条件中的一项。
