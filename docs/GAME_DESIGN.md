# 游戏设计

## 核心循环

查看日程与状态 → 点击地点 → 选择行动或处理事件 → 按难度应用即时结果 → 推进时段 → 检查高压危机与延迟后果 → 自动存档。

## 固定规格

- 时间：7 天，每天早晨、上午、下午、晚上、深夜。
- 地点：宿舍、图书馆、教学楼、实验室、食堂、操场/校园道路。
- 数值：学习、项目、精力、压力、四名 NPC 关系；AI 依赖度隐藏。
- 关键节点：第 5 天上午考试，第 7 天下午项目展示。
- 结局：全面发展、学习强者、技术达人、AI 协作高手、温暖校园、AI 过度依赖、压力失控。

选择不能只替换台词。代表性事件至少同时影响即时数值和后续事件、关系或结局条件中的一项。

## 难度与压力危机

| 难度 | 压力增长 | 学业收益 | 精力消耗 | 眩晕阈值 |
| --- | ---: | ---: | ---: | ---: |
| 简易 | 100% | 100% | 100% | 88 |
| 中等 | 125% | 82% | 115% | 76 |
| 困难 | 165% | 60% | 140% | 64 |

- 中等为新游戏默认难度；难度选定后随存档保存。
- 旧存档缺少难度字段时按简易处理，保持此前的数值节奏。
- 高压达到阈值后，在下一次行动结算时触发眩晕危机。玩家可以暂停恢复、冒险记录关键点，或在关系足够时向同伴求助。
- 难度同时削弱压力缓解和精力恢复，实际结算数值会直接显示在结果界面。
- 中等和困难还会在每次行动后增加“期末环境压力”；低精力、临近考试/展示且准备不足会进一步提高该数值。
