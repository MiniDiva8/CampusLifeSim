# 变更记录

## 0.4.0-demo

- 将确认通过的竞赛界面原型迁移到正式流程，新增可交互的 `AdaptiveSceneView`。
- 地点、事件、结果与压力危机统一使用独立照片舞台和右侧选择面板，不再以大卡片遮盖背景。
- 根据旋转后的原图比例自动采用竖幅、标准横幅或宽幅布局，照片不拉伸、不重新编码、不二次压缩。
- 固定日程事件按答疑、考试、项目会议、彩排等语义选择教学楼、图书馆或实验室照片。
- 选择卡会显示难度调整后的主要数值影响；隐藏 AI 依赖度仍不显示具体数值。
- 主菜单、校园总览、路途、角色初始化、暂停、设置、制作信息和结局统一为深色竞赛展示视觉。
- 道路过渡改为等比放大后的轻微平移，修正 EXIF 旋转竖图在滚动时被挤压的问题。
- UI 冒烟测试扩展到 33 项，覆盖真实按钮回调、语义照片、自适应竖图宽度与照片/面板分离。

## 0.3.0-demo

- 将项目内 65 张照片替换为与用户源文件 SHA-256 一致的原图，不再缩放或二次压缩。
- 新增原比例“完整前景 + 同图柔和铺底”的宽屏显示方式，避免照片被强制铺满裁切。
- 在显示层应用 EXIF 方向元数据，修正理综楼走廊、宿舍、道路及部分食堂照片横倒的问题，同时保持原 JPEG 字节不变。
- 降低事件遮罩、卡片和选择按钮的不透明度，并适度缩小事件卡片，让照片内容更清楚。
- 操场照片会明确说明打网球、游泳、篮球、羽毛球、跑步等真实活动。
- 教学区照片会显示理综楼、理综楼走廊、知新楼、董明珠楼、青年会客厅等真实场景名称。
- 场景事件支持 `{scene_name}` 与 `{scene_activity}` 占位符，使标题、正文、选项和结果与当前照片一致。

## 0.2.0-demo

- 新增简易、中等、困难三档难度，新游戏默认推荐中等。
- 难度统一影响压力增长与缓解、精力消耗与恢复、学习/项目/考试/展示收益。
- 高压达到难度阈值后自动触发眩晕危机，并提供恢复、冒险推进和关系求助三种处理方式。
- 将用户提供的长曝光光轨照片用于压力过载背景，并加入持续的视觉拉扯动效。
- 难度、危机次数和选择结果随自动存档保存；旧存档继续采用原本的简易节奏。

## 0.1.1-demo

- 接入用户提供的 64 张校园照片，并按六个地点、昼夜道路与菜单分类。
- 地点进入时随机选择背景，同一地点不会连续显示同一张；选择结果和随机历史随存档保存。
- 加入约两秒的校园道路滚动过渡，傍晚和夜间自动使用夜景池。
- 新增照片方向校正与尺寸优化导入工具、运行时资源清单和相应测试。
- 更新 Windows debug 构建并完成 EXE/PCK 离线启动验证。

## 0.1.0-demo

- 初始化 Godot 4.7.1 独立项目与长期开发文档。
- 实现七天时间、玩家状态、NPC 关系、延迟后果和固定种子 AI。
- 加入 32 个事件、六个地点、一个考试、一次展示和七个结局。
- 完成主菜单、校园地图、地点行动、设置、暂停、自动存档和结局流程。
- 选择性接入 Maaack 场景加载、音频与暂停基础。
