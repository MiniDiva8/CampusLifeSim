# 变更记录

## 0.8.0-demo

- 全面升级为“山大夜航 · Neo Glass”竞赛视觉体系，统一主菜单、角色初始化、校园地图、事件、结算、设置、暂停、路途和结局。
- 新增项目原创的分辨率无关屏幕取样毛玻璃着色器，包含受控模糊、色调融合、饱和度、细微颗粒、边缘高光和柔和投影。
- 新增共享 `GlassPanel`，把毛玻璃背景与清晰文字内容分层；照片舞台保持独立，不对原始校园照片做模糊、拉伸、重编码或压缩。
- 按钮和地点卡新增鼠标跟随聚光、悬停抬升、按压缩放、键盘焦点高亮与柔和阴影；“减少界面动效”会关闭位移动画。
- 地点入口改为更清晰的信息层级，直接展示真实地点、活动描述、进入动作和时段消耗。
- 设置滑杆、状态条与道路进度条使用统一的半透明轨道、发光填充和圆形高光抓手。
- 校园总览背景新增程序化暗色渐变、山大红/青绿/蓝色柔光和细网格，不增加外部图片依赖。
- UI 冒烟测试新增玻璃面板、悬停控制器、真实悬停缩放、地点卡、滑杆与道路进度样式检查。

## 0.7.0-demo

- 新增原创程序化校园声景，覆盖主菜单、校园总览、道路、学生公寓、蒋震图书馆、教学区、人工智能学院机房、齐园餐厅和风雨操场。
- 五个游戏时段映射为白天、傍晚和深夜三个声音状态，人群活动、脚步、风声和夜间虫声会随时间改变。
- 两秒道路过渡会从原地点交叉淡化到道路声，抵达时再交叉淡化到目的地，并在路途中预热目标循环。
- 六个地点分别加入可辨识的声音细节：风扇与键盘、翻页、楼道脚步、设备底噪、餐具碰撞、球声和远处哨声。
- 压力达到 60 后叠加独立低频身体反馈，强度随压力变化，恢复后平滑消失，并受既有“压力状态音效”开关控制。
- 所有新增声音均为固定参数与固定种子生成，没有下载第三方音频，也不依赖网络。
- 新增独立声景冒烟测试，并通过核心规则、点击音效、环境音、UI 流程、完整七天模拟、视觉捕获和 Windows 导出验证。

## 0.6.0-demo

- 用项目自有 `AudioDirector` 替换统一的 620Hz 按钮提示音，加入 14 类具有不同节奏、音高和材质的原创程序化交互声音。
- 按钮通过语义元数据选择悬停、普通点击、确认、返回、开关、地点进入、事件选择和危险操作音效；同类声音加入轻微音高变化和触发冷却。
- 音频总线扩展为 Master、Music、SFX、UI、Event、Stress 和 Ambience，并在 Master 末端加入 -1 dB 安全限制器。
- 设置页面增加音乐、交互与事件、校园环境三个独立音量，以及可单独关闭的压力状态音效；旧设置文件会自动补齐新字段。
- 增加八声部并发上限、总线淡入淡出、退出前音频清理和独立音频冒烟测试，避免快速点击堆叠与退出时资源残留。
- 当前阶段没有下载或加入外部音乐与音效文件；校园环境声将在下一阶段单独建立并登记来源。

## 0.5.0-demo

- 将六个地图入口替换为山东大学中心校区真实语境：中心校区学生公寓、蒋震图书馆、中心校区教学区、人工智能学院机房、齐园餐厅和风雨操场。
- 蒋震图书馆与阅读空间照片从教学场景池归回图书馆，固定答疑、考试和展示分别绑定理综楼、董明珠楼与青年会客厅照片。
- 风雨操场、综合体育馆、游泳馆、室外田径场和室外网球场按照片分别显示，不再用一个操场名称覆盖所有运动。
- 教学、咖啡馆和青年会客厅场景提供照片匹配的行动文案；选择结果继续使用当时展示的具体行动名称。
- 32 个事件保持数量和数值结构不变，并加入数据划分、随机种子、可复现性、虚构论文、模型评价和 AI 课程答辩等专业细节。
- 主菜单、路途、场景 HUD、加载与结局加入克制的山大红、中心校区、1901及校训元素，不使用山东大学校徽。
- 新增 `启动游戏（安全方式）.cmd`：在 WDAC 阻止未签名 EXE 的开发电脑上，通过已安装的官方签名 Godot 4.7.1 加载 PCK，不关闭或绕过系统安全功能。
- 项目版本更新为 `0.5.0-demo`，学校信息来源记录在素材与来源文档中。

## 0.4.0-demo

- 将确认通过的竞赛界面原型迁移到正式流程，新增可交互的 `AdaptiveSceneView`。
- 地点、事件、结果与压力危机统一使用独立照片舞台和右侧选择面板，不再以大卡片遮盖背景。
- 根据旋转后的原图比例自动采用竖幅、标准横幅或宽幅布局，照片不拉伸、不重新编码、不二次压缩。
- 固定日程事件按答疑、考试、项目会议、彩排等语义选择教学楼、图书馆或实验室照片。
- 选择卡会显示难度调整后的主要数值影响；隐藏 AI 依赖度仍不显示具体数值。
- 主菜单、校园总览、路途、角色初始化、暂停、设置、制作信息和结局统一为深色竞赛展示视觉。
- 道路过渡改为等比放大后的轻微平移，修正 EXIF 旋转竖图在滚动时被挤压的问题。
- UI 冒烟测试扩展到 33 项，覆盖真实按钮回调、语义照片、自适应竖图宽度与照片/面板分离。

## 0.3.0-demo

- 将项目内 65 张照片替换为与用户源文件 SHA-256 一致的原图，不再缩放或二次压缩。
- 新增原比例“完整前景 + 同图柔和铺底”的宽屏显示方式，避免照片被强制铺满裁切。
- 在显示层应用 EXIF 方向元数据，修正理综楼走廊、宿舍、道路及部分食堂照片横倒的问题，同时保持原 JPEG 字节不变。
- 降低事件遮罩、卡片和选择按钮的不透明度，并适度缩小事件卡片，让照片内容更清楚。
- 操场照片会明确说明打网球、游泳、篮球、羽毛球、跑步等真实活动。
- 教学区照片会显示理综楼、理综楼走廊、知新楼、董明珠楼、青年会客厅等真实场景名称。
- 场景事件支持 `{scene_name}` 与 `{scene_activity}` 占位符，使标题、正文、选项和结果与当前照片一致。

## 0.2.0-demo

- 新增简易、中等、困难三档难度，新游戏默认推荐中等。
- 难度统一影响压力增长与缓解、精力消耗与恢复、学习/项目/考试/展示收益。
- 高压达到难度阈值后自动触发眩晕危机，并提供恢复、冒险推进和关系求助三种处理方式。
- 将用户提供的长曝光光轨照片用于压力过载背景，并加入持续的视觉拉扯动效。
- 难度、危机次数和选择结果随自动存档保存；旧存档继续采用原本的简易节奏。
