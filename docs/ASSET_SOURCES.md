# 素材与第三方来源

## 正式游戏素材

- 校园地图、图标和 UI 使用 Godot 原生控件与项目自制矢量/程序化图形。
- 地点、菜单和道路背景使用项目所有者于 2026-07-23 提供的校园照片，原始来源目录为父级工作区的 `游戏场景图片/`。
- 项目内的 64 张正式副本只做 EXIF 方向校正、等比例缩放与 JPEG 压缩；未进行生成式修改。
- 分类包括宿舍、图书馆、教学楼、实验室、食堂、操场、白天道路、夜晚道路和菜单界面。
- 父级目录根部的长曝光光轨照片未被纳入游戏，因为它不属于已确认的校园地点或道路分类。
- 照片由用户提供并指定用于本项目；公开分发前，项目所有者仍应确认照片中可识别人物及场所的肖像权、隐私和拍摄许可。
- 未下载或使用来源不明的图片、音乐、字体或音效。

## 图片导入方式

- `tools/import_user_backgrounds.ps1` 从父级 `游戏场景图片/` 读取原图，在 `assets/backgrounds/` 生成最长边 1920 像素、质量 88 的项目副本。
- 导入脚本不覆盖、改名或删除父级原图。
- 运行时清单位于 `data/backgrounds.json`；新增或移除照片时需要同步更新清单。
