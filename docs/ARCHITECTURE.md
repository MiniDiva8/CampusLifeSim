# 架构

项目分为五层：

1. JSON 内容层：地点、NPC、事件、AI 建议与结局。
2. 核心规则层：时间、会话状态、事件条件与效果。
3. 服务层：内容加载校验、自动存档、设置持久化。
4. 表现层：主菜单、角色初始化、地图、事件、暂停、设置和结局。
5. 验证层：无界面规则测试、内容校验和 Windows 构建检查。

界面只能通过明确接口修改游戏状态，JSON 只描述受控条件和效果，不执行脚本。

`DifficultyRules` 在 `EventEngine` 应用效果前统一调整数值，确保事件 JSON 保持单一基础数值。`GameSession` 只保存难度 ID，不复制倍率配置；旧存档自动回退到简易规则。
